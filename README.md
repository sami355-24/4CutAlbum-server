# 👋 개요
> 젊은 세대 사이에서 즉석사진을 찍으며 시간을 보내고 인화한 사진을 나눠갖는 것은 하나의 문화가 되었습니다. 
4CutAlbum은 이를 겨냥해 찍은 사진을 모아놓는 디지털 앨범입니다. 그러나 찍은 사진은 오직 사진을 저장한 사용자만이 확인할 수 있으며 공유하지 못한다는 점이 아쉬웠습니다.
이를 저희는 이를 개선사항으로 여겨 4CutAlbum의 고도화를 진행하였습니다.

--------------

# 📱 기능
⚠️  [원본 레포지토리](https://github.com/GDSC-KNU/4CutAlbum-server)와 달리 본 레포지토리는 제가 구현한 것 위주로 작성하였습니다.
- 내 사진들을 조회할 수 있어야 한다.
- 공유된 사진들을 조회 할 수 있어야 한다.
- 해시태그, 업체명 필터링, 업체명 선택, 사람 인원수 1인/2인/3인/4인/5인+  으로 검색이 가능하다.
- 사진은 해시태그, 인원 수, 업체명을 통해 공유할 수 있다.
